# Physics Lab · Физическая лаборатория

Интерактивная лаборатория для изучения физических уравнений через симуляции в браузере. Three.js отображает рассчитанные состояния; параметры позволяют менять начальные условия и сравнивать модели.

[Открыть лабораторию](https://pom4h.github.io/physics/) · [Репозиторий](https://github.com/Pom4H/physics)

## Что уже реализовано

Текущий каталог посвящён квантовой механике: семь орбиталей водорода, свободный волновой пакет, туннелирование, две щели, когерентный осциллятор, суперпозиция уровней бесконечной потенциальной ямы и отдельная лаборатория спиноров Паули, Дирака и Вейля. Спинорные модели можно сравнить при одном распределении импульса.

Орбитали и яма вычисляются аналитически; остальные скалярные сцены используют численное решение уравнения Шрёдингера. Спинорный режим вычисляет точную спектральную эволюцию заданного семейства свободных пакетов. Первые шесть сцен исключают спин; переключение спинорного режима не добавляет релятивистские поправки к атому или двум щелям.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --directory docs
```

Открыть [http://localhost:8000](http://localhost:8000). Нужен браузер с WebGL 2, ES-модулями и import maps. Страницу следует открывать через HTTP: загрузка модулей через `file://` ограничивается браузером. Three.js и OrbitControls находятся в `docs/vendor`; сборка, CDN и серверная часть для работы лаборатории не требуются.

Проверки выполняются в Node.js; установка npm-зависимостей не нужна:

```sh
npm run check
npm test
```

`npm run check` проверяет синтаксис модулей и целостность статического приложения. `npm test` запускает физические тесты со встроенным `node:test` (эквивалентно `node --test tests/*.test.mjs`). Размещаемый на статическом хостинге каталог — `docs/`.

## Модель и единицы

Для исходных скалярных волновых сцен используется безразмерная форма уравнения одной нерелятивистской массивной частицы:

$$
i\partial_t\psi=\left(-\frac12\nabla^2+V-iW\right)\psi,
\qquad \rho=|\psi|^2.
$$

Здесь численно положено $\hbar=m=1$. Для перевода в физические единицы можно выбрать длину $L_0$ и массу $m$: тогда $t_0=mL_0^2/\hbar$, $E_0=\hbar^2/(mL_0^2)$. Без такого выбора показания времени и энергии не являются секундами и электронвольтами.

В водороде используются **атомные единицы**: расстояния в боровских радиусах $a_0$, энергии в хартри $E_h$. Для неподвижного ядра $H=-\tfrac12\nabla^2-1/r$, $E_n=-1/(2n^2)$. Доступны `1s`, `2s`, `2pz`, `2px`, `3dz2`, `3dxz`, `3dxy`. Это модель неподвижного протона без поправки на приведённую массу, спина и тонкой структуры. Формулы и нормировки приведены в [учебнике UT Austin](https://farside.ph.utexas.edu/teaching/qmech/Quantum/node82.html).

### Что означает изображение

- **Плотность** $|\psi|^2$ задаёт вероятность на единицу длины, площади или объёма. Вероятность в области получается интегрированием. Высота двумерной поверхности кодирует плотность; физические координаты этой сцены — только $x,y$.
- **Фаза** — аргумент комплексной функции. Противоположные знаки реальной орбитали соответствуют относительной фазе $\pi$. Цвета не обозначают электрический заряд.
- **Точки орбитали** — возможные результаты повторных измерений положения одного электрона. Они выбираются из $|\psi|^2$ и остаются неподвижными; перемещение камеры меняет ракурс. Это не траектории и не множество электронов.
- **Стационарность:** отдельная орбиталь приобретает общую фазу $e^{-iE_nt}$, а её плотность сохраняется. Реальные $p_x$ и некоторые $d$-орбитали являются комбинациями состояний с разными $m$; определённого значения $L_z$ у такой комбинации может не быть.
- **Радиальный график** показывает $P(r)=r^2|R_{nl}(r)|^2$. Сферический якобиан уже учтён. В выборке отсекается конечный радиальный хвост; `tailProbability` и `retainedProbability` возвращаются явно, без изменения формул орбитали.

### Волновые пакеты

Начальная гауссова функция пропорциональна

$$
\exp\left[-\frac{(x-x_0)^2}{4\sigma^2}+ik_0(x-x_0)\right].
$$

`sigma` — стандартное отклонение **плотности**, $\Delta k=1/(2\sigma)$. В свободном пространстве:

$$
\langle x\rangle=x_0+k_0t,\qquad
\sigma_x(t)=\sigma\sqrt{1+\left(\frac{t}{2\sigma^2}\right)^2}.
$$

Эти зависимости служат аналитическим эталоном для численного решения; см. [MIT, Gaussian Wavepacket](https://ocw.mit.edu/courses/5-73-quantum-mechanics-i-fall-2018/93d60ea36737349acdeb5afdef6fd500_MIT5_73F18_Lec3.pdf).

В осцилляторе $V=\omega^2x^2/2$ когерентная начальная ширина равна $1/\sqrt{2\omega}$. Центр движется как $x_0\cos\omega t+(k_0/\omega)\sin\omega t$, ширина сохраняется. Иная начальная ширина в общем случае даёт сжатое состояние с меняющейся шириной; см. [MIT, разделы 4.2–4.3](https://ocw.mit.edu/courses/8-05-quantum-physics-ii-fall-2013/79a8091ef4f18d8e3ff76a097e8db33c_MIT8_05F13_Chap_06.pdf).

В яме ширины $L$ используются собственные функции $\sqrt{2/L}\sin(n\pi u)$, где $u\in[0,1]$, с энергиями $n^2\pi^2/(2L^2)$. `wellMix` задаёт вероятность второго уровня: амплитуды двух состояний равны $\sqrt{1-\text{wellMix}}$ и $\sqrt{\text{wellMix}}$. Эволюция каждой фазы вычисляется точно; начальный множитель дискретной нормировки фиксирован во времени.

## Спиноры Паули, Дирака и Вейля

Открыть `#spinor/compare`, `#spinor/pauli`, `#spinor/dirac` или `#spinor/weyl` после адреса лаборатории. Пространственная координата одна — $x$. В каждой её точке сохраняются все комплексные компоненты соответствующего спинора; поляризация имеет три компоненты.

### Гамильтонианы и базис

Во всех трёх режимах $i\hbar\partial_t\Psi=H\Psi$, $\hat p=-i\hbar\partial_x$. Интерфейс использует $\hbar=c=1$, а массу позволяет менять независимо. Это отдельные единицы спинорного режима: они не совпадают с атомными единицами сцены водорода. Без выбора физического масштаба длины значения $m,p,x,t$ не являются килограммами, обычными единицами импульса, метрами и секундами. Если выбрать длину $L_0$, согласованные масштабы — $t_0=L_0/c$, $E_0=\hbar c/L_0$ и $m_0=\hbar/(cL_0)$.

| Модель | Комплексные компоненты | Гамильтониан |
| --- | --- | --- |
| Паули | $(\psi_\uparrow,\psi_\downarrow)$ | $H_P=p^2I_2/(2m)+\hbar\Omega\sigma_z/2$ |
| Вейль | $(\chi_{R\uparrow},\chi_{R\downarrow})$ **или** $(\chi_{L\uparrow},\chi_{L\downarrow})$ | $H_R=+cp\sigma_x$, $H_L=-cp\sigma_x$ |
| Дирак | $(\chi_{L\uparrow},\chi_{L\downarrow},\chi_{R\uparrow},\chi_{R\downarrow})$ | $H_D$ ниже |

$$
H_D=
\begin{pmatrix}
-cp\sigma_x & mc^2I_2\\
mc^2I_2 & cp\sigma_x
\end{pmatrix}.
$$

Здесь $\sigma_x,\sigma_y,\sigma_z$ — матрицы Паули. Метки $\uparrow,\downarrow$ относятся к проекциям спина на **ось $z$**. Две компоненты одного спинора Вейля не являются левой и правой хиральностями: у каждой хиральности свой двухкомпонентный спинор. У Дирака это два блока по две компоненты. Массовый член связывает блоки; при $m=0$ они разделяются.

Спинор Вейля — также тип представления, используемый при записи массивного поля Дирака; само это название не означает, что любое поле, записанное двухкомпонентно, физически безмассово. В отдельном режиме Вейля здесь выбрана именно свободная безмассовая динамика. Основа этих соглашений: [Tong, The Dirac Equation, разделы 4.4 и 4.7](https://www.damtp.cam.ac.uk/user/tong/qft/qfthtml/S4.html) и [Dreiner, Haber, Martin, Two-component spinor techniques](https://arxiv.org/abs/0812.1594). Первичная работа: [Dirac, The quantum theory of the electron, 1928](https://doi.org/10.1098/rspa.1928.0023).

Член $\hbar\Omega\sigma_z/2$ у Паули включён только в отдельном опыте с прецессией; в сравнении $\Omega=0$. Это заданная однородная **спиновая** связь. Орбитальное действие магнитного поля на заряженную частицу, векторный потенциал и сила Лоренца в этом опыте не рассчитываются. Однородная связь вращает поляризацию, сохраняя пространственную плотность свободного пакета.

### Общий спектр и положительная энергия

На дискретных волновых числах $k=2\pi q/L$, $p=\hbar k$, во всех сравниваемых моделях задаётся

$$
|A(k)|^2\propto \exp[-2\sigma^2(k-k_0)^2],\qquad k>0.
$$

Нулевая и найквистовская моды исключены; сумма оставшихся вероятностей нормируется в единицу. Амплитуда $A(k)$ получает фазу $e^{-ikx_0}$, задающую начальное положение. Параметр `sigma` — стандартное отклонение пространственной плотности соответствующего **неусечённого непрерывного скалярного гауссова пакета**. Он задаёт спектр обратно пропорционально: $\Delta p\approx\hbar/(2\sigma)$. После отсечения $p\le0$, дискретизации и подготовки спинора фактическая `sigmaX` может отличаться от `sigma`.

Для $p>0$ выбирается $\zeta_h=(1,h)^T/\sqrt2$, $\sigma_x\zeta_h=h\zeta_h$. Здесь $h=\pm1$ — собственное значение нормированного оператора спиральности $\boldsymbol\Sigma\cdot\mathbf p/|\mathbf p|$; для двухкомпонентного блока $\boldsymbol\Sigma=\boldsymbol\sigma$. Проекция самого спина вдоль импульса равна $\hbar h/2$, а не $h$. Положительноэнергетический спинор Дирака:

$$
u_h(p)=
\begin{pmatrix}
\sqrt{\frac{E-hcp}{2E}}\,\zeta_h\\
\sqrt{\frac{E+hcp}{2E}}\,\zeta_h
\end{pmatrix},
\qquad E=\sqrt{c^2p^2+m^2c^4}.
$$

Начальное состояние Дирака равно $A(k)u_h(p)$. Вейль использует $A(k)\zeta_h$ с $h=+1$ для правой хиральности и $h=-1$ для левой. При этих $p>0$ и $E>0$ оба пакета Вейля движутся вправо со скоростью $c$, имея противоположную поляризацию. Паули в сравнении получает тот же $A(k)\zeta_h$.

Идентичным является **распределение импульса**. Начальная пространственная плотность Дирака может немного отличаться от остальных из-за зависимости $u_h(p)$ от $p$. Отрицательные энергии в начальное состояние Дирака и Вейля не включены. Поэтому здесь нет интерференции положительной и отрицательной энергетических ветвей и связанного с ней дрожательного движения. При $m=0$ пакет Дирака точно совпадает с выбранным пакетом Вейля; Паули при $m=0$ неприменим и исключается из сравнения.

В отдельном режиме Паули начальный спин задаётся углами:

$$
\zeta(\theta,\phi)=
\begin{pmatrix}
\cos(\theta/2)\\ e^{i\phi}\sin(\theta/2)
\end{pmatrix}.
$$

Его поляризация вращается как
$(\sin\theta\cos(\phi+\Omega t),\sin\theta\sin(\phi+\Omega t),\cos\theta)$.
При $p/(mc)\ll1$ свободная пространственная динамика Паули приближается к динамике Дирака. При большом импульсе нерелятивистская формула $\langle v\rangle=\langle p\rangle/m$ может превысить $c$; интерфейс показывает отношение $p_{\rm rms}/(mc)$ и отмечает потерю применимости этого приближения.

### Эволюция и наблюдаемые

`Spinor1D` хранит начальные коэффициенты $C_a(k)$, для которых $\sum_{a,k}|C_a(k)|^2=1$. В заданный абсолютный момент времени каждый положительноэнергетический коэффициент Дирака и Вейля умножается на $e^{-iE(k)t/\hbar}$. У Паули используется кинетическая энергия $p^2/(2m)$ и дополнительные фазы $e^{\mp i\Omega t/2}$ для $\uparrow,\downarrow$.

Затем обратное FFT вычисляет

$$
\psi_a(x,t)=\frac1{\sqrt L}\sum_k C_a(k,t)e^{ikx}.
$$

Эта эволюция точна для выбранного конечного спектрального семейства; ошибка шага интегрирования по времени отсутствует. Остаются ошибки округления и ограничения конечных области и спектра. Во время эволюции состояние повторно не нормируется.

Отображаются плотность $\rho=\sum_a|\psi_a|^2$ и поляризация
$\mathbf n=\Psi^\dagger\boldsymbol\Sigma\Psi/\rho$, где для Дирака
$\boldsymbol\Sigma=\operatorname{diag}(\boldsymbol\sigma,\boldsymbol\sigma)$.
Спин равен $\hbar\mathbf n/2$. В узлах плотности направление не определено; стрелки в малых хвостах подавляются для отображения.

Ток вероятности рассчитывается из компонент:

$$
j_P=\frac{\hbar}{m}\operatorname{Im}(\psi^\dagger\partial_x\psi),\quad
j_D=c(\chi_R^\dagger\sigma_x\chi_R-\chi_L^\dagger\sigma_x\chi_L),\quad
j_W=\pm c\,\chi^\dagger\sigma_x\chi.
$$

Знак последнего выражения соответствует правой/левой хиральности. Показанная средняя скорость — $\int j\,dx/\int\rho\,dx$. Доли $L$ и $R$ интегрируются по всей области. Для подготовленного свободного пакета Дирака с $E>0$ эти суммарные доли сохраняются:

$$
\langle\gamma^5\rangle=P_R-P_L
=\sum_k|A(k)|^2\frac{hcp}{E}.
$$

Наличие массовой связи не означает периодического переключения всего пакета между хиральностями.

В трёхмерном представлении физическая координата пакета — только $x$. Высота кривых линейно кодирует плотность в одном фиксированном масштабе. Разные дорожки моделей и небольшие смещения компонент **по глубине** служат компоновке; дополнительными пространственными координатами волновой функции они не являются. Стрелки показывают трёхмерную поляризацию: физическая ось $z$ направлена вверх, физическая $y$ — в отрицательную глубину.

Панель компонент показывает их интегральные доли, а колонка $\Delta\phi/\pi$ — **локальную относительную фазу в максимуме общей плотности**. Опорной выбирается первая компонента с заметной амплитудой в этой точке; общая фаза исключается. Знак «—» означает слишком малую амплитуду для устойчивого сравнения фаз. Это не средняя фаза по всему пакету.

### API и конечная область

Модуль не зависит от DOM или Three.js:

```js
import { Spinor1D } from './docs/physics/spinor.mjs';

const packet = new Spinor1D({
  model: 'dirac', // 'pauli' | 'dirac' | 'weyl'
  n: 512,
  length: 96,
  x0: -12,
  sigma: 2.4,
  k0: 1.6,
  mass: 1,
  helicity: 1,
  chirality: 1,
  hbar: 1,
  c: 1,
});

packet.setTime(3);        // абсолютное t >= 0
packet.step(0.1, 2);      // перейти к t + 0.2
packet.stats();          // снимок наблюдаемых
packet.reset({ mass: 0 }); // новое начальное состояние, t = 0
```

`helicity` выбирает $\zeta_h$ для Дирака и начальный спин Паули по умолчанию; `chirality` выбирает правый или левый Вейль. Для Паули можно явно передать `theta` и `phi` в радианах и `omega`. Масса Паули должна быть положительной. Изменение `n` или `length` требует нового экземпляра.

| Данные | Семантика |
| --- | --- |
| `components` | Массив компонент с `label`, `re`, `im`. Комплексные амплитуды в координатном представлении. |
| `density`, `componentDensity` | Общая плотность и плотности отдельных компонент. |
| `spinX`, `spinY`, `spinZ` | Локальная безразмерная поляризация; в численно малых хвостах выставляется ноль. |
| `currentDensity` | Ток вероятности вдоль $x$. |
| `initialSpectrum`, `kgrid`, `pgrid`, `spectralProbability`, `spectralEnergy` | Начальные коэффициенты и спектральные данные; доступны для чтения, не для произвольного изменения состояния. |
| `stats()` | `norm`, `xMean`, `sigmaX`, `meanMomentum`, `rmsMomentum`, `meanEnergy`, `meanKineticEnergy`, `meanVelocity`, средняя поляризация, доли компонент и хиральностей. |
| `stats().periodicEdgeProbability` | Интеграл плотности в полосах $|x|\ge0.4L$. Это вероятность у краёв, не поглощённая вероятность. |

Массивы переиспользуются при `setTime`; сохранять независимый кадр следует копированием. Распространение произвольного добавленного отрицательноэнергетического спинора, внешние пространственные потенциалы и произвольные начальные поля этим API не предусмотрены.

В интерфейсе `n=512`, `length=96`, $\Delta x=0.1875$, область $x\in[-48,48)$. На графике и в сцене виден центральный интервал $[-28,28]$. Время ограничено $0\le t\le20$; при быстром движении Паули контроллер уменьшает верхнюю границу, чтобы основной пакет оставался в видимой области.

Границы **периодические**, поглотителя в спинорном модуле нет. Интерфейс ограничивает время наблюдения, а не поглощает или обнуляет часть состояния. Полная нормировка и доли считаются по всей области, включая невидимые малые хвосты. При самостоятельном вызове API на больших временах пакет может обойти периодическую область; тогда линейные `xMean` и `sigmaX` зависят от выбора её разреза.

## Численный метод скалярных сцен и границы расчёта

`wave.mjs` применяет симметричное расщепление Стрэнга:

$$
\psi(t+h)\approx
e^{(-iV-W)h/2}\mathcal F^{-1}
e^{-i|k|^2h/2}\mathcal F
e^{(-iV-W)h/2}\psi(t).
$$

Кинетическая часть вычисляется через FFT; общий метод имеет второй порядок по времени при достаточной гладкости решения и потенциала. Для реального потенциала без поглощения шаг сохраняет дискретную норму, но сохранение нормы само по себе не доказывает точность. Теория: [Suzuki, Suryanarayana, Nuyens — Fourier method and Strang splitting](https://arxiv.org/pdf/1808.06357).

Параметры ниже — значения по умолчанию в физических модулях; интерфейс может передавать свои настройки.

| Сцена | Сетка и существенные параметры |
| --- | --- |
| 1D | `n=512`, длина 64, $\Delta x=0.125$; максимальный подшаг 0.025. |
| Барьер 1D | $V_0=8$, ширина 0.75, $k_0=3$, $\sigma=2$; максимальный подшаг 0.01. Потенциал на краях усредняется по длине перекрытия ячейки со стенкой. |
| Осциллятор | $\omega=0.32$, $k_0=0$, начальная ширина 1.25. |
| Две щели | `n=128`, область $32\times32$, $\Delta x=0.25$; максимальный подшаг 0.008. При `n=256` шаг сетки 0.125. |
| Стенка и щели 2D | Высота 12, толщина 1.5, ширина щели 1.8, расстояние между центрами 5, сглаживание краёв 0.18. Начальный $k_0=2.5$. |

`step(dt, steps)` автоматически дробит `dt`, если он превышает `maxStep`. Большой шаг от вызывающего кода не отменяет установленный предел интегрирования.

FFT задаёт периодические границы. Поглотитель $W\ge0$ плавно возрастает в краевых полосах; он уменьшает возврат волны, сохраняя конечный размер расчётной области и возможные отражения от поглотителя. Начальное состояние нормируется один раз. Затем `norm` показывает оставшуюся вероятность, `absorbed` — накопленную потерю, `accounted = norm + absorbed` — их баланс. Средние координаты после поглощения условны на оставшейся части состояния.

`left`, `right`, `barrier` — пространственные области. Слева в начале находится падающий пакет; отражённым его можно считать после разделения. `transmitted` добавляет к правой области вероятность, поглощённую в правой полуплоскости. В 2D туда входит и поглощение у верхнего/нижнего края справа от стенки. Это пространственная оценка прохождения, а не интеграл тока через детектор.

В конечном пакете энергии распределены: центральное значение $k_0^2/2$ отличается от среднего. Для 1D начальный спектр даёт `initialKineticEnergy` и `aboveBarrierFraction`. Прохождение надбарьерных компонент не является туннелированием. Формула моноэнергетического прохождения из [UT Austin, Square Potential Barrier](https://farside.ph.utexas.edu/teaching/qmech/Quantum/node48.html) требует усреднения по спектру для сравнения с пакетом; усреднение потенциала по ячейкам также влияет на результат.

`screenProfile(x)` возвращает **мгновенную плотность** на ближайшем сечении сетки. Это не накопленные попадания детектора. Двумерная стенка конечна и сглажена; узкие щели, резкие края и малые длины волн требуют повторной проверки с меньшими $\Delta x$ и $\Delta t$.

## Проверки и производительность

Тесты проверяют нормировку, узлы и уравнение $H\psi=E\psi$ для орбиталей, радиальные моменты и статистику выборки. Для пакетов проверяются аналитические центры и ширины, стационарность собственного состояния ямы, баланс поглощения, разделение отражённого/прошедшего пакета и чувствительность к шагу времени. Для двух щелей сравниваются шаги 0.008/0.004 и сетки 128²/256² при $t=6$, включая форму профиля сечения. Это проверки заданных случаев; новые параметры требуют своей проверки сходимости. Состояние выполнения тестов определяется выводом команды, а не этим документом.

Спинорные тесты отдельно проверяют общий спектр и норму, собственное уравнение $H_Du=Eu$, безмассовый предел, перенос пакета Вейля со скоростью $c$, ток Дирака и сохранение интегральной хиральности, знак прецессии Паули и смену знака спинора при $2\pi$, нерелятивистский предел после удаления энергии покоя, обратимость и валидацию параметров.

Расчёт FFT выполняется JavaScript-кодом на CPU, Three.js отображает результат через WebGL. Стоимость шага составляет $O(N\log N)$ в 1D и $O(N^2\log N)$ на квадратной 2D-сетке. Удвоение разрешения по каждой оси увеличивает число ячеек в четыре раза. Частота кадров зависит от устройства, размера сетки и количества шагов между кадрами; этот репозиторий не устанавливает гарантию FPS и не содержит сравнительного бенчмарка рендереров.

Исходные скалярные сцены не включают спин и релятивистские поправки. Спинорный режим добавляет описанное выше семейство одночастичных состояний Паули, Дирака и Вейля, однако лаборатория не моделирует взаимодействие нескольких частиц, фермионную статистику, рождение пар, квантованные фотонные или глюонные поля.

Расчёт 2D работает в Web Worker; основная нить отображает последнюю рассчитанную волну. Одна уже запущенная порция расчёта может завершиться после нажатия паузы, максимум на 0.128 единицы модельного времени.

Автоматические физические тесты не заменяют проверку изображения и управления в браузере. Показатель FPS в интерфейсе измеряется на устройстве пользователя.
